# MDCR2026

2026年8月2日〜16日のモンゴル旅行と、8月8日〜16日の Mongolia Desert Challenge Rally 2026 に関する情報を管理するリポジトリです。

## 重要

- 参加者は本人・妻の2人で、ツーリングはタンデムです。
- ツアー資料の基本便（8月8日 OM504／8月16日 OM501）はツアー①の標準日程です。
- 本人たちの実予約は、往路が8月2日 OM502、復路が8月16日 OM509です。
- 航空機利用時のバッグ構成は、1人につき「預け荷物（スーツケース）・手荷物（SSERバッグ）・身の回り品（小型バックパック）」の3個、2人で合計6個です。
- 渡航時パッキングとツーリング中の持ち物は別のチェックリストとして管理します。
- ツアー走行期間は8月9日〜15日、予定走行距離は約1,300 kmです。
- モンゴルはジュネーブ条約非加盟のため、国際運転免許証だけでは現地運転の法的根拠にならないとの注意書きがあります。主催者の案内と保険条件を必ず再確認します。

## 構成

- `itinerary/`: 全旅行およびツアーの日程
- `touring/`: 走行ルート、安全、2人分の装備、車両整備
- `checklists/`: 出発前、渡航時パッキング、ツーリング中の持ち物、書類のチェックリスト
- `bookings/`: 航空券、宿泊、保険
- `finance/`: 予算、現金、カード
- `emergency/`: 緊急連絡先
