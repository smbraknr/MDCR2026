# Mongolia 2026 Travelogue / Album

> **Status: 🚧 IN PROGRESS**
>
> 作業ブランチ: `travelogue/album-2026`
>
> 対象期間: 2026-08-02 〜 2026-08-16（15日間）

## 目的

2026年8月のモンゴル旅行について、文章と写真を組み合わせた旅行記を制作し、後年読み返したときに「何があり、どこへ行き、何を感じたか」を思い出せるアルバム冊子として残す。

写真の見栄えだけを優先する写真集ではなく、出来事・人物・食事・移動・トラブル・小さな記憶も含めて旅行を再構成できる記録を目指す。

## 最終成果物

- 文章と写真による旅行記
- 1ページ A4 縦、見開き A3 横を基本とするアルバム冊子
- 印刷用最終データ（形式・印刷サービスは後工程で決定）

## 素材と管理場所

| 種類 | 管理場所 | 方針 |
|---|---|---|
| 旅行記本文・制作記録 | Git / このリポジトリ | 履歴を残す |
| 事前旅程・予約・装備情報 | 既存の `itinerary/` 等 | 旅行記作成時の参照資料 |
| 写真原本 | Google Photos | 原本アーカイブ |
| 採用写真の記録 | `travelogue/photos/` | 写真IDと採否理由を記録 |
| 印刷用の選定済み高解像度画像 | 制作フォルダ | Google Photos から選定後に書き出す |
| 最終成果物 | PDF / 印刷冊子 | 完成時に保存方法を確定 |

## 役割分担

### ChatGPT
- 記憶・資料の整理
- 本文案の作成と推敲
- 写真候補の比較・推薦
- ページ構成・レイアウト案の提案
- 不整合や未確認事項の抽出

### 人間
- 記憶内容の確定
- 写真の最終採否
- 文章表現の最終判断
- レイアウトの最終判断
- 印刷前の最終承認

## 制作工程

1. 素材・情報源の棚卸し
2. 15日分の出来事・記憶を日別に記録
3. 日別本文を作成
4. 写真候補を選定
5. 本文と写真を統合してページ割りを決定
6. レイアウト作成
7. 校正・試し刷り
8. 最終PDF・冊子化

進捗は [PROGRESS.md](./PROGRESS.md) を正とする。

現在の作業方法・構成・実行済み内容をまとめて把握する場合は [WORKING_BASELINE.md](./WORKING_BASELINE.md) を参照する。これは今後の制作作業に合わせて更新する。

## 重要な編集原則

- 「旅行前の予定」と「実際に起きたこと」を混同しない。
- 不明な事実は推測で補完せず、未確認として残す。
- 本文を整える前に、記憶の断片を落とさないことを優先する。
- 写真の技術的な良否だけでなく、記憶を呼び戻す価値を重視する。
