# A3 Spread Trial Wireframes — 2026-08-02 to 2026-08-04

**Status:** 試作

**Purpose:** 写真・本文・余白のバランスを確認するためのテキストベースのワイヤーフレーム

## 共通ルール
- 外周安全余白: 約12 mm
- 中央折り周辺: 重要な顔・文字を置かない
- 本文: 9〜11 pt 相当を想定
- 写真キャプション: 7〜8.5 pt 相当
- タイトル: 24〜32 pt 相当
- 試作中のみ写真IDをキャプションに付与
- 原則として主役写真1枚、準主役2〜3枚、小写真2〜4枚

# 試作評価項目

実レイアウト化した後、以下を確認する。

1. 見開きを開いた瞬間に各日の主題が分かるか。
2. 写真だけを追っても時間の流れが概ね読めるか。
3. 写真が重要な文章を圧迫していないか。
4. 小写真が多すぎて「写真一覧」に見えないか。
5. 千香の感情・観察が場所説明に埋もれていないか。
6. 8/3・8/4は2見開きへ分割した方が読みやすくないか。

この評価後に、最終ページ割りへ進む。
