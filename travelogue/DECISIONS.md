# Decisions

## 2026-09-20

### 管理場所
- MDCR2026 リポジトリ配下の `travelogue/` で制作する。
- 長期作業になるため、専用ブランチ `travelogue/album-2026` を使用する。
- 完成まで `main` へ直接作業内容を混在させない。

### 冊子
- 1ページ A4 縦、見開き A3 横相当を基本とする。
- 文章と写真を組み合わせたアルバム旅行記とする。
- 主目的は、後から読み返して旅行中の出来事を思い出せること。

### 視点・一次メモの扱い
- ユーザーから提供される旅行メモは、特記がない限りすべて千香の視点として扱う。
- 主語が省略されている記述も、原則として千香の体験・観察・感想として解釈する。
- 晃教など他者の行為・会話は、千香が見聞きした出来事として記録する。
- 本文作成時も千香視点を基準とし、視点を無意識に混在させない。

### 写真
- 原本は Google Photos に保存する。
- Git には原則として写真原本を保存しない。
- ChatGPT が候補を提案し、人間が最終決定する。

### レイアウト
- ChatGPT が候補を提案し、人間が最終決定する。

### 制作順序
素材・記憶整理 → 本文 → 写真選定 → ページ構成 → レイアウト → 校正 → 冊子化。

## 2026-09-21

### 8/2〜8/4 レイアウト試作の承認
- 8/2〜8/4のA3横5見開き試作を、人間が「このレイアウトでよい」と承認した。
- 8/2は1見開き、8/3は2見開き、8/4は2見開きを基準案として確定する。
- 承認済みレイアウトの原則は `layout/style-guide.md` に固定し、残りの日程へ展開する。
- 新情報や前提変更がない限り、8/2〜8/4のレイアウト構造は再検討しない。
- White Tara / Green Tara の明確な作品写真が見つかった場合など、内容を変える強い新情報がある場合のみ局所的に再評価する。

### 本制作への移行
- 8/2〜8/4で「メモ → 本文 → 写真選定 → ページ割り → 実レイアウト」の制作経路が成立した。
- 以後は試作案を増やすより、同じ制作経路を8/5以降へ展開する。
