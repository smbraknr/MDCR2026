# Sources

旅行記作成時に参照できる情報源の一覧。

## Git 内の既存資料

- `../itinerary/`: 旅行前に作成した日程・予定
- `../touring/`: 走行ルート、装備、車両関連情報
- `../bookings/`: 航空券・宿泊・保険
- `../shopping/`: 買い物計画
- `../finance/`: 旅行費用関連
- `../checklists/`: 出発・装備チェック

既存資料の多くは旅行前に作成された計画である。旅行記本文へ転記する際は、実際に起きた事実であることを別途確認する。

## 外部素材

- Google Photos: 写真原本
- GPS / GPX: 実走ルート・場所特定
- 航空券・予約確認
- レシート
- スクリーンショット
- 地図
- 当時のメッセージやメモ
- 参加者から提供された写真

## 情報の優先順位

1. 当日の写真・GPS・時刻付き記録などの一次記録
2. 当時作成したメモ・メッセージ
3. 予約記録・公式資料
4. 記憶
5. 旅行前の予定

食い違いがあれば、自動的に予定を実績扱いしない。
