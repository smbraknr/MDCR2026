# Photo Selection

写真原本は Google Photos に置き、このファイルには選定情報だけを記録する。

## 選定基準
- その日の出来事を説明できるか
- 後で見たときに記憶を呼び戻せるか
- 人物・場所・食事・移動・トラブルなど旅行の多様な面を残せるか
- 類似写真と重複していないか
- 見開きで大きく使う価値があるか
- 本文だけでは伝わりにくい情報を補えるか

## 記録形式

| 日付 | 写真ID/ファイル名 | 内容 | 候補 | 想定用途 | 備考 |
|---|---|---|---|---|---|
| | | | A/B/C | 大写真/小写真/記録用 | |

A: 強い採用候補 / B: 比較・補完候補 / C: 記録用
