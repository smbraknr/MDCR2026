# 装備・車両

## 前提

- ツーリング参加者は本人・妻の2人
- 本人が運転し、妻はタンデム同乗する
- 個人装備は2人分、工具などは共用品として管理する
- ここでは渡航用の荷造りではなく、ツーリング中に使用・携行する装備を管理する

## 本人用ライディング装備

- [ ] ヘルメット
- [ ] シールドまたはゴーグル
- [ ] オフロードブーツ（膝下まで保護できるもの）
- [ ] グローブ
- [ ] ライディングジャケット／パンツ
- [ ] 肘・肩・胸・背中・膝のプロテクター
- [ ] ネックブレース（任意・推奨）
- [ ] 防水レインウェア
- [ ] 防寒着
- [ ] SENA ST1
- [ ] 3 Lキャメルバック
- [ ] アミノバイタル
- [ ] スマートフォンとSP Connect用ケース
- [ ] 日本の運転免許証
- [ ] 国外運転免許証

## 妻用ライディング装備

- [ ] ヘルメット
- [ ] シールドまたはゴーグル
- [ ] オフロードブーツ（膝下まで保護できるもの）
- [ ] グローブ
- [ ] ライディングジャケット／パンツ
- [ ] 肘・肩・胸・背中・膝のプロテクター

## 2人の共用品・車載品

- [ ] ロープ 10 m
- [ ] バイクのスペアキー
- [ ] モバイルバッテリー
- [ ] 充電ケーブル
- [ ] 救急用品
- [ ] ヘッドランプ／懐中電灯
- [ ] 工具・パンク対応品
- [ ] 緊急連絡先
- [ ] 2人分の書類コピー

## バイク整備（遅くとも5月初旬〜中旬）

- [ ] タンデムと積載を前提に、サスペンション・空気圧・最大積載量を確認
- [ ] 必要なガード類を選定・装着
- [ ] エンジンオイル／フィルター交換
- [ ] オフロード対応タイヤへ交換
- [ ] チェーン／スプロケット点検・必要時交換
- [ ] バッテリー点検（始動不良または3年以上使用なら交換検討）
- [ ] 前後ブレーキパッド点検（2 mm以下なら交換）
- [ ] エアクリーナー清掃または交換
- [ ] タンデム状態でSENA、装備、積載を含む実走確認
- [ ] その他の不安箇所を解消

資料のタイヤ例: Kenda K82、Mitas ENDURO XT+、Metzeler KAROO 4、Michelin ANAKEE WILD。

## コンテナ同梱を検討できる物

2人分のライディングジャケット、パンツ、ブーツ、プロテクター類、およびそれらの収納バッグに限定。片道だけの利用は不可で、帰路は使用済み・濡れた状態の装備を長期間密閉する可能性があります。紛失時には再輸入時の関税リスクもあります。
