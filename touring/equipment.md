# 装備・車両

## 前提

- ツーリング参加者は本人・妻の2人
- 本人のみが運転し、妻はタンデム同乗する
- 渡航時の荷造りとは別に、ツーリング中の車載位置を管理する

# 車載レイアウト

## 基本方針

- タンデム走行のため、二人ともバックパックやウエストポーチを運転中は装備しない
- 飲料水はライダーのみキャメルバックで携行する
- 走行中によく使用するものはトップケースへ収納する
- 軽量でかさばるものはサイドバッグへ収納する
- 車両受け取り時、出発前に作業が必要なものは「艤装品」としてまとめる

## 1. 艤装品

バイク受領後、最初に取り付ける装備。

- [ ] SP Connect用 RAM Mountセット
- [ ] GARMIN用 RAM Mountセット
- [ ] 固定用ゴムバンド
- [ ] ゼッケンステッカー

### 艤装時の作業

- [ ] ステッカーを貼付
- [ ] タンデム用シートクッションへ空気を追加
- [ ] タンデム用シートクッションを取り付け
- [ ] シートカバーを取り付け
- [ ] キャメルバックをライダーのジャケットに内蔵
- [ ] SENA本体をヘルメットに接続
