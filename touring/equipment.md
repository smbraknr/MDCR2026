# 装備・車両

## ライディング装備

- [ ] ヘルメット
- [ ] シールドまたはゴーグル
- [ ] オフロードブーツ（膝下まで保護できるもの）
- [ ] グローブ
- [ ] ライディングジャケット／パンツ
- [ ] 肘・肩・胸・背中・膝のプロテクター
- [ ] ネックブレース（任意・推奨）
- [ ] 防水レインウェア
- [ ] 防寒着
- [ ] 水筒またはハイドレーション
- [ ] バックパック
- [ ] SENAインカム
- [ ] バイクのスペアキー

## バイク整備（遅くとも5月初旬〜中旬）

- [ ] 必要なガード類を選定・装着
- [ ] エンジンオイル／フィルター交換
- [ ] オフロード対応タイヤへ交換
- [ ] チェーン／スプロケット点検・必要時交換
- [ ] バッテリー点検（始動不良または3年以上使用なら交換検討）
- [ ] 前後ブレーキパッド点検（2 mm以下なら交換）
- [ ] エアクリーナー清掃または交換
- [ ] その他の不安箇所を解消

資料のタイヤ例: Kenda K82、Mitas ENDURO XT+、Metzeler KAROO 4、Michelin ANAKEE WILD。

## コンテナ同梱を検討できる物

ライディングジャケット、パンツ、ブーツ、プロテクター類、およびそれらの収納バッグに限定。片道だけの利用は不可で、帰路は使用済み・濡れた状態の装備を長期間密閉する可能性があります。紛失時には再輸入時の関税リスクもあります。
