# 荷造りチェックリスト

## 機内持込み（重要品）

- [ ] パスポート、航空券、予約控え
- [ ] 国外運転免許証、日本の運転免許証、登録証書
- [ ] 現金、クレジットカード
- [ ] 保険証券、緊急連絡先
- [ ] ヘルメット
- [ ] 常用薬
- [ ] スマートフォン、充電器、ケーブル
- [ ] モバイルバッテリー、予備リチウムイオン電池
- [ ] カメラ等の貴重品
- [ ] 1日分程度の着替え

## 受託手荷物

- [ ] ライディング装備（コンテナに入れない物）
- [ ] 衣類、下着、靴下、寝間着
- [ ] スニーカー、サンダル、水着（温泉用）
- [ ] タオル、歯ブラシ、石鹸、シャンプー類
- [ ] 帽子、日焼け止め、サングラス、リップクリーム
- [ ] トイレットペーパー
- [ ] ヘッドランプ／懐中電灯
- [ ] 絆創膏、胃腸薬等、プロテクトJ1
- [ ] 塩タブレット、補給食、サプリメント
- [ ] マルチ変換プラグ（B／B3／C対応）

## 荷物制限（資料記載のエコノミー）

- 受託: 23 kg以内、3辺合計158 cm以内、1個
- 機内: 8 kg以内、55×40×20 cm、1個
- 小型身の回り品: 1個
- 100 ml超の液体・刃物は受託へ
- リチウムイオン電池、モバイルバッテリー、ライターは受託に入れない

実際のOM502／OM509の予約クラス・航空券条件を優先して再確認します。
