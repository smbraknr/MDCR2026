# 荷造りチェックリスト

## 前提

- 参加者: 本人・妻の2人
- 渡航時の荷物: 1人3個、2人で合計6個
- 渡航時の荷造りと、ツーリング中に携行する物は分けて管理する
- 各品目の「本人用／妻用／共用」と収納先を出発前に確定する

## MIAT手荷物条件（資料記載のエコノミー）

- 受託手荷物: 1人1個、23 kg以内、3辺合計158 cm以内
- 機内手荷物: 1人1個、8 kg以内、55×40×20 cm
- 小型身の回り品: 1人1個
- 2人分の想定は、受託2個・機内2個・身の回り品2個の合計6個
- 100 ml超の液体・刃物は受託手荷物へ
- リチウムイオン電池、モバイルバッテリー、ライターは受託手荷物に入れない

- [ ] OM502／OM509の実予約クラスに適用される最新条件を確認
- [ ] SSERバッグを8 kg以内に収めた
- [ ] 小型バックパックが身の回り品として認められる寸法であることを確認
