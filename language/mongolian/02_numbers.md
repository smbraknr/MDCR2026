# モンゴル語の数字 1〜100

モンゴル国で使用されるキリル文字表記の数字と、日本語話者向けのカタカナ発音をまとめた。

> [!NOTE]
> カタカナは発音の近似である。特に語末の子音や `х`、`р`、`л` は、日本語の発音とは異なる。

> [!TIP]
> 値段や電話番号は聞き違えやすい。重要な数字は、スマートフォンの電卓画面を見せて確認する。

## 数の作り方

- 11〜19は、`арван`（10の連結形）＋1〜9。
- 21〜29は、`хорин`（20の連結形）＋1〜9。
- 同様に、30以上も十の位の連結形＋一の位で作る。
- 100は `зуу`（ゾー）。

## 値段・大きな数

金額では、後ろに `төгрөг`（トゥグルグ）を付ける。日常会話では文脈上明らかなら省略されることもある。

| 数字 | モンゴル語 | カタカナ発音 |
|---:|---|---|
| 100 | нэг зуу / зуу | ネグ ゾー／ゾー |
| 500 | таван зуу | タヴァン ゾー |
| 1,000 | нэг мянга / мянга | ネグ ミャンガ／ミャンガ |
| 5,000 | таван мянга | タヴァン ミャンガ |
| 10,000 | арван мянга | アルヴァン ミャンガ |
| 20,000 | хорин мянга | ホリン ミャンガ |
| 50,000 | тавин мянга | タヴィン ミャンガ |
| 100,000 | зуун мянга | ゾーン ミャンガ |
| 1,000,000 | нэг сая | ネグ サヤ |

| 日本語 | モンゴル語 | カタカナ発音 |
|---|---|---|
| いくらですか | Хэд вэ? | ヘド ウェ？ |
| 5,000トゥグルグです | Таван мянган төгрөг. | タヴァン ミャンガン トゥグルグ |
| 合計はいくらですか | Нийт хэд вэ? | ニート ヘド ウェ？ |
| 数字で書いてください | Тоогоор бичиж өгнө үү. | トーゴール ビチジ オグヌー |

> [!NOTE]
> 数を単独で言う形と、名詞の前で使う形が異なる場合がある。例：`тав`（5）→ `таван мянга`（5,000）、`зуу`（100）→ `зуун төгрөг`（100トゥグルグ）。表現をまとまりで覚える。

## 時刻・日付・番号

| 日本語 | モンゴル語 | カタカナ発音 |
|---|---|---|
| 何時ですか | Хэдэн цаг вэ? | ヘデン ツァグ ウェ？ |
| 8時 | Найман цаг. | ナイマン ツァグ |
| 8時30分 | Найман цаг гучин минут. | ナイマン ツァグ ゴチン ミノート |
| 何日ですか | Хэдний өдөр вэ? | ヘドニー ウドゥル ウェ？ |
| 電話番号は何番ですか | Утасны дугаар хэд вэ? | オタスニー ドガール ヘド ウェ？ |
| 部屋番号は何番ですか | Өрөөний дугаар хэд вэ? | ウルーニー ドガール ヘド ウェ？ |

電話番号・部屋番号・車両番号は、桁ごと、または2〜3桁のまとまりで読まれることがある。聞き取れない場合は `Тоогоор бичиж өгнө үү.`（数字で書いてください）を使う。
