# モンゴル語キリル文字：旅行用読み方ガイド

看板・メニュー・地図を、キリル文字だけでもおおよそ読めるようにするための早見表。モンゴル国の標準語（ハルハ・モンゴル語）を対象とする。

> [!IMPORTANT]
> カタカナとラテン文字は発音の目安。実際のモンゴル語では、母音調和、弱母音の脱落、語末子音などにより、綴りどおりに一音ずつ読まないことがある。まずは **Ө・Ү・Х・Л・Р** を区別すると通じやすい。

## 日本語にない・異なる音

### Ө ө（ö）

- **舌の位置**：日本語の「エ」寄りの位置から少し奥。舌を強く引かない。
- **唇**：「オ」のように丸める。
- **日本語との違い**：「オ」ほど奥舌ではなく、「ウ」ほど狭くない。
- **コツ**：「エ」の舌のまま唇だけを「オ」にする。最初は「ォ」と短く出す。
- 例：`дөрөв`（4）、`төгрөг`（トゥグルグ）。

### Ү ү（ü）

- **舌の位置**：日本語の「イ」の位置に近い。
- **唇**：「ウ」のようにしっかり丸める。
- **日本語との違い**：日本語の「ウ」は唇の丸みが弱く、舌も後ろ寄り。
- **コツ**：「イー」と言う舌のまま、唇だけをすぼめて「ウー」。
- 例：`сүү`（牛乳）、`үгүй`（いいえ）。

### Х х（kh）

- **舌の位置**：舌の後部を軟口蓋へ近づける。
- **日本語との違い**：日本語の「ハ」は息が滑らかだが、х は喉の奥に摩擦がある。
- **コツ**：うがい直前のように喉の奥を狭め、息だけを強く出す。母音を足して「ク」にしない。
- 例：`хоол`（食事）、`хаана`（どこ）。

### Г г（g）

- **舌の位置**：前寄り母音（э・ө・ү・е・и）の語では日本語のガ行に近い。奥舌母音（а・о・у）の語では、舌の後部をさらに奥へ寄せる。
- **日本語との違い**：語中・語末では弱くなったり、摩擦音・長母音の一部のように聞こえたりする。
- **コツ**：すべてを強い「グ」で読まず、まず母音を明瞭にする。`га` は喉の奥寄り、`гэ` は通常のゲに近い。
- 例：`газар`（場所）、`эмнэлэг`（病院）。

### Л л（l）

- **舌の位置**：舌先を上の前歯のすぐ後ろにつける。
- **息**：舌の両側から摩擦を伴って出す。
- **日本語との違い**：日本語のラ行のように舌先を一度だけ弾かない。
- **コツ**：英語の l の形を保ち、左右から「ス」に似た息を出してから母音へ移る。
- 例：`талх`（パン）、`төлбөр`（支払い）。

### Р р（r）

- **舌の位置**：舌先を上の歯茎近くへ軽く当てる。
- **日本語との違い**：日本語のラ行より明確に弾く。長い場合は軽く震わせる。
- **コツ**：まず日本語の「ラ」をやや強く。無理に巻き舌を長く続ける必要はない。
- 例：`ресторан`（レストラン）、`өрөө`（部屋）。

## 読み方の基本規則

- 長母音は同じ母音を2文字で書く：`аа, ээ, ий, оо, өө, уу, үү`。短母音より長く保つ。
- `ай, эй, ой, уй, үй` などは二重母音。最後の `й` は短い「イ」。
- 語末の `б, г, д` は日本語話者には `п, к, т` 寄りに聞こえることがある。
- 子音の連続に、はっきりした日本語の母音を毎回挟まない。例：`банк` は「バンク」より **バン(ク)**。
- 外来語はロシア語式の綴りを保つことがあり、上表だけでは読み切れない場合がある。

## 母音調和

モンゴル語では、原則として一つの語の母音が同じグループにまとまる。接尾辞にも複数形があり、語幹に合わせて選ばれる。

| グループ | 主な母音 | 例 |
|---|---|---|
| 奥舌（男性）母音 | а・о・у | `зам`（道）、`хоол`（食事） |
| 前舌（女性）母音 | э・ө・ү | `өрөө`（部屋）、`сүү`（牛乳） |
| 中立母音 | и | どちらの語にも現れる |

例：疑問の `уу / үү` は、`Хол уу?`（遠いですか）では **уу**、`Зөв үү?`（正しいですか）では **үү** になる。旅行者は接尾辞を作るより、フレーズ単位で覚えるのが安全。

## 強勢と弱母音

- 一般的な説明では、**語の最初の音節が目立ちやすい**。ただし「強勢」の分析には諸説があり、長母音を含む音節や語末が際立つ場合もある。
- 強く読む位置を誇張するより、**長母音を十分長く、短母音を短く**読むほうが通じやすい。
- 第1音節より後の短母音は弱くなり、会話ではほとんど聞こえないことがある。例：`байна` は綴りどおりの「バイナ」より「バイン」に近く聞こえる。
- カタカナに書かれた母音をすべて同じ強さで発音しない。

## よく間違える発音

| 誤りやすい読み | 通じやすくするポイント | 例 |
|---|---|---|
| ө を普通の「オ」にする | エ寄りの舌＋丸い唇 | `төгрөг` |
| ү を日本語の「ウ」にする | イの舌＋丸い唇 | `сүү` |
| х を「ク」と読む | 母音を足さず、喉の奥の摩擦音 | `мах` |
| л と р を同じラ行にする | л は舌を固定、р は舌先を弾く | `гол` / `гэр` |
| 長母音を短くする | 二重母音字は長く保つ | `цай`, `хоол`, `сүү` |
| すべての子音に母音を足す | 子音連続は短くまとめる | `банк`, `карт` |
| `ц` をサ行で読む | 「ツ」に近く読む | `цай`, `цаг` |
| `з` を常に日本語のズにする | 語頭ではツ／ズの中間も意識 | `зам`, `зураг` |
| `ж` を弱いジにする | ジ／チの中間をやや強く | `жижиг` |
| `нг` を常に「ング」と切る | 一続きの鼻音になる場合がある | `мөнгө` |
